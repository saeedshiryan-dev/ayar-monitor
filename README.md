# Ayar Monitor

سامانه پایش صندوق طلای عیار

## اهداف پروژه
- دریافت اطلاعات واقعی معاملات صندوق عیار
- نمایش نمودارهای یک‌ساعته و چهارساعته
- محاسبه RSI، MACD و EMA
- نمایش قیمت آخرین معامله، قیمت پایانی و NAV به‌صورت جداگانه
- نمایش منبع داده و زمان آخرین به‌روزرسانی

## اصول صحت داده
- هیچ داده یا کندل ساختگی نمایش داده نشود.
- اطلاعات قدیمی یا ناقص با هشدار مشخص شوند.
- کندل‌ها فقط از داده‌های واقعی و زمان‌دار ساخته شوند.
- منطقه زمانی محاسبات تهران باشد.
- اطلاعات ورود و رمزها در مخزن عمومی قرار نگیرند.
