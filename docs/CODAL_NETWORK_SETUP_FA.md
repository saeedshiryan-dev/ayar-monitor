# راه‌اندازی مسیر پایدار دریافت کدال

اسکریپت دریافت گزارش پرتفوی عیار اکنون از retry کنترل‌شده، صفحه‌بندی نتایج، و مسیر proxy اختیاری پشتیبانی می‌کند.

## چرا مسیر جایگزین لازم است؟
کدال در بعضی زمان‌ها به IPهای خارج از ایران پاسخ نمی‌دهد. خطای DNS/timeout در GitHub-hosted runner را نمی‌توان با تغییر User-Agent یا افزایش timeout به‌تنهایی رفع کرد. برای دریافت پایدار باید درخواست‌ها از یک اتصال با خروجی اینترنت ایران عبور کنند.

## تنظیم یک‌باره در GitHub
1. در مخزن `ayar-monitor` وارد **Settings → Secrets and variables → Actions** شو.
2. در **New repository secret** نام را دقیقاً `CODAL_HTTP_PROXY` بگذار.
3. مقدار را URL یک HTTP/HTTPS proxy معتبر با خروجی ایران قرار بده؛ نمونه قالب (نه آدرس واقعی): `http://USERNAME:PASSWORD@HOST:PORT`.
4. Secret را ذخیره کن و از Actions، گردش‌کار **Refresh Ayar Fund NAV History** را با **Run workflow** اجرا کن.

مقدار proxy نباید در فایل‌های مخزن یا لاگ‌ها نوشته شود. اسکریپت فقط اعلام می‌کند proxy تنظیم شده یا نه و آدرس/رمز آن را چاپ نمی‌کند.

## اگر proxy در دسترس نیست
گردش‌کار همچنان تلاش مستقیم را انجام می‌دهد و با retry محدود ادامه می‌دهد. در صورت شکست، گزارش قبلیِ بارگذاری‌شده حفظ می‌شود و گزارش قدیمیِ جایگزین به‌عنوان گزارش رسمی تازه ثبت نمی‌شود. این رفتار عمداً محافظه‌کارانه است.

## آزمون موفق واقعی
موفقیت فقط وقتی تأیید می‌شود که خروجی JSON دارای `status: "ok"`، `report.is_fallback_report: false`، تاریخ دوره گزارش و برگه‌های Excel باشد. سبزشدن صرفِ GitHub Actions یا وجود یک فایل قدیمی، اثبات دریافت تازه از کدال نیست.
